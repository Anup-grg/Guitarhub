Firmware notes

Current firmware: 4.20. Presets built on 3.x open correctly but should be re-saved once on 4.20 so the new cab engine renders as intended.

The Helix stores each preset as a single .hlx file that references IR slots rather than embedding audio. When you import a preset that uses custom IRs, load those .wav files into the same slots the author used, or the cab block will fall back to a stock cab.

  • Helix Floor / LT / Rack and Native all share the .hlx format.
  • HX Stomp presets are interchangeable but limited to 6 blocks.
  • Setlists can hold up to 128 presets each.

How to import

  1. Update the Helix to firmware 4.20 using HX Edit or Line 6 Updater.
  2. Open HX Edit and connect over USB.
  3. Drag the preset onto an empty slot, or use File → Import Preset.
  4. Import any bundled .wav IRs into IR slots 1–2.
  5. Save the preset and assign snapshots to footswitches.
